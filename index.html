Robinhood Chain · $ROOK

Compute routed,
not promised.

Rook is a marketplace for verified AI inference. Renters buy metered access to a model catalog; GPU owners list idle capacity and get paid when a request actually lands on it. Every route is logged before it's billed.

Check the contract Read the source

Three moving parts

01

Renters send a job

A request names a model and a budget. Rook's router picks a live GPU that can serve it inside that budget, not the first one that answers.

02

Owners list a card

Anyone with an idle GPU can register it against the catalog. It earns when it serves a verified job, nothing when it sits idle.

03

$ROOK settles the route

Each completed job is a settled transaction on Robinhood Chain — the renter pays, the GPU owner is paid, and the route is on record.
